# AirClock

一个基于 C++ 的图形时钟程序，使用自定义造型渲染表盘，实时显示当前时间。

## 功能

- 模拟时钟表盘，带有时针、分针、秒针
- 抽象外观造型，非标准表盘
- 实时刷新，每秒更新一次

## 运行方式

用 Visual Studio 打开 `Project6.sln`，直接按 **Ctrl + F5** 运行即可。
